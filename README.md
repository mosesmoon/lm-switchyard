# LM-Switchyard

**Next-Gen Model Manager** — a cross-platform manager for vLLM servers (Linux, Windows, Web).

- Adopts the vLLM servers you already run, locally or over SSH, without rebuilding them
- Just-in-time model switching for agents behind one OpenAI-compatible endpoint
- Per-agent and per-session dashboard: time to first token, tokens per second, history
- Hugging Face model library with download and fit checks
- Interface in 12 languages

Status: design phase. The design document is under review in [`docs/DESIGN.md`](docs/DESIGN.md) (Traditional Chinese).
